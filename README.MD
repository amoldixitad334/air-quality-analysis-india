# Air Quality Analysis of Indian Cities

## Project Overview

This project analyzes air quality data from different Indian cities using Python. It explores Air Quality Index (AQI), pollutant levels, monthly trends, and differences between cities.

## Objectives

* Analyze AQI across Indian cities.
* Compare air quality in Delhi and Mumbai.
* Identify monthly air quality trends.
* Study relationships between air pollutants and AQI.
* Visualize findings using charts and a correlation heatmap.

## Tools and Technologies

* Python
* Google Colab
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Dataset

The project uses the Air Quality Data in India dataset from Kaggle.

Dataset: https://www.kaggle.com/datasets/rohanrao/air-quality-data-in-india

## Key Findings

* Ahmedabad had the highest average AQI among the cities analyzed.
* Delhi's average AQI was higher than Mumbai's.
* November had the highest average monthly AQI in the dataset.
* PM10 showed a strong positive correlation with AQI.

## How to Run

1. Download `Air_Quality_Analysis.ipynb` from this repository.
2. Open Google Colab.
3. Upload the notebook.
4. Upload the required dataset file, `city_day.csv`.
5. Run the notebook cells in order.
